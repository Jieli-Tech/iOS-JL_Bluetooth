杰理之家SDK_IOS_V1.14.0

● 补丁描述

日期: 2026/01/27
APP版本: V1.6.0
SDK版本: V1.14.0
该SDK在RCSP协议基础上实现, 需要配合对应功能 SDK 使用

● 补丁等级：C

● 修改内容

  1. 新增功能

  • 增加 LE Audio 与 RCSP 并存功能

  • 增加 AI 翻译功能

  • 增加 Auracast Broadcast 功能

  • 增加 Gatt Over BR/EDR 连接方式的支持

  1. 修复功能

  • 修改彩屏仓本地资源

● 注意事项

警告

  1. 需保证设备连接成功后再初始化 JLTranslationManager 并下发配置参数。

  2. 需根据场景正确设置 JLTranslateSetMode（采样率/通道数/编码类型）。

  3. OPUS/JLA_V2 编解码与语音识别/翻译/TTS 需按示例接入第三方服务，并在合成后通过 trWriteAudio 写回设备。

  4. GATT Over BR/EDR 连接方式下，需在用户先在系统蓝牙搜索页面进行设备的 BR/EDR 连接，才可发现设备。
