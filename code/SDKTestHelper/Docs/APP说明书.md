# APP说明书

## 术语说明
- `DevHandle`：设备端文件系统或资源的句柄/分区入口，用于定位读写目标区域
- `ATT`：GATT over EDR 通讯方式，适用于部分设备的特定蓝牙传输通道
- `JLUI`：设备端 UI 框架，支持彩屏资源下发与显示逻辑

## 快速上手
- 步骤1：打开蓝牙与相关权限（定位/麦克风等，视功能而定）
- 步骤2：进入 `搜索设备` 扫描并选择目标设备 → 连接成功
- 步骤3：进入 `默认设置` 验证常用能力（TWS/彩屏/查找设备/天气等）
- 步骤4：如需资源下发，进入 `文件传输` 完成资源准备与传输
- 步骤5：需要升级时进入 `更新` → 执行 `OTA/4G OTA`
- 步骤6：按需体验翻译、Auracast、NFR/ImitationNFR 等高级功能

## 系统要求与权限
- 平台版本：iOS 13.0 及以上（不支持 iOS 12.0 以下）
- 蓝牙权限：所有蓝牙相关功能需开启系统蓝牙并授予权限
- 定位权限：部分蓝牙扫描场景需要定位权限以获取广播信息
- 麦克风权限：语音录制/翻译等音频功能需要麦克风权限
- 网络权限：云服务/4G OTA 等需要稳定网络连接

## 日志与反馈
- 开启方式：`设置` → 启用日志开关并选择级别（建议调试阶段打开）
- 查看渠道：控制台输出与界面提示（如轻提示/状态文本）
- 提交问题：建议附带日志片段、设备型号、操作步骤与时间点，便于快速定位

## 1.1 连接说明

当前使用的默认连接方式是自定义蓝牙连接方式，目的是为了更好的搜索到其他不同类型广播报的设备，当然也可以选择为关闭，在设置==>自定义蓝牙连接，中关闭即可。

选择 ATT 连接说明，部分设备需要使用 GATT OVER EDR 的通讯方式，也就是这里所说到的 ATT 连接方式，这里需要进入到设置==> 使用 ATT 通讯，勾选打开，会有一个弹窗，在弹窗中输入通讯的服务 UUID，一般公版默认的是：**AE00**

建议操作步骤：
- 打开系统蓝牙与定位权限（如被提示授权，按需允许）
- 进入 `设置`：根据设备类型选择是否开启“自定义蓝牙连接”
- 启用 `使用 ATT 通讯`（仅针对需要 GATT over EDR 的设备），并在弹窗中填写服务 UUID（默认 `AE00`）
- 返回主界面进行扫描与连接；连接成功后进入各功能页进行测试

提示：
- 认证开关需设备端与其他端同时关闭/打开，否则连接后可能出现认证失败或功能受限
- 无法发现服务/特征时，优先检查连接方式（ATT vs 常规 BLE）与 UUID 配置是否正确

## 1.2 设备历史记录

设备历史记录里头记录了已连接过的设备历史记录，也有当前正在连着的设备，还有就是从系统的搜索记录里的历史记录。

这三者的区别是：

| 设备历史记录                                                 | 已连接                                                       | 系统搜索的历史记录                                           |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 用户手动连接过的历史记录，不一定存在附近，只是数据库中的记录 | 当前正在连接的设备，不一定有这个通讯句柄，但是系统是已经连着的。 | 系统搜索过的历史记录，不一定存在附近，只是系统中记录的搜索记录 |

## 1.3 文件传输

### - 大文件

大文件点击进入后，需要预先选择 DevHandle 设备句柄，进入对应的存储区域进行数据读取或者进行大文件写入。

文件路径准备：
- 将目标固件/资源文件放入 App 可访问的目录（例如 `Documents/TransportFiles` 或 `_R.path.otas`）
- 若初次进入列表为空，可使用第三方工具（如爱思助手）将文件拷贝到上述目录后重试

常见问题与建议：
- 若显示空列表，请检查目录与文件扩展名是否正确；返回页面重新进入可刷新列表
- 传输过程中保持蓝牙与前台运行，避免切到后台导致中断
 - 完成后可在设备端或对应浏览页面验证资源是否生效



### - 同步联系人

进入后可以同步与设备之间的联系人信息，这个需要设备支持，部分设备可能不支持。

### - 表盘

表盘这个只是一个统称，它包含了带屏的所有类型设备，但要求设备端支持和使用了：**JLUI**  的框架。用于下发表盘或者表盘背景图等内容。

### - 小文件

手表设备专用功能。设备端将部分文件信息存储于 `flash`，支持读取、擦除、写入等基础操作。
使用建议：在执行写入/擦除前，确认分区与权限，避免误操作导致数据丢失。
操作步骤建议：
- 选择目标分区/条目 → 读取当前内容 → 视需求执行写入或擦除 → 观察结果提示
- 写入前备份关键条目，避免不可逆风险

### - 文件浏览

一般用于浏览设备端指定 DevHandle 设备句柄的内容，仅仅提供下载功能和浏览功能。

提示：部分设备文件系统层级较深，建议按目录逐级浏览，避免一次性加载过多导致卡顿。
操作步骤建议：
- 进入根目录 → 按需展开子目录 → 选择文件执行下载/预览 → 在本地目录验证文件



### - 传GIF到设备

本质上跟表盘是差不多意思的，都是将资源内容打包，发送到设备端，同样的可以参考上述的大文件传输，APP 端默认是没有对应的 GIF 内容的，需要通过其他的辅助工具，如爱思助手，将GIF 内容拉入到 APP 中，但是存放的路径为：Document/gif2rgb 


## 1.4 OTA 升级（蓝牙 OTA）

### 前置条件
- 设备已连接（主界面连接成功后，`更新` 菜单可进入 OTA 页面）
- 固件文件已存放在 App 可访问目录（通常 `_R.path.otas`）

### 操作步骤
- 打开：主界面 → `更新` → `OTA`
- 选择文件：点击 `选择 OTA 文件`，从列表中选择目标固件包（界面显示文件名）
- 初始化：点击 `初始化` 执行目标特征确认（可能会有加载提示）
- 开始升级：点击 `开始 OTA`，界面显示阶段状态与进度百分比（准备→升级→重启/回连）
- 中断升级：点击 `停止 OTA` 可取消当前升级流程

### 回连与续传
- 升级过程中若提示 `reconnect`，需按设备 UUID 回连；部分场景支持断点续传（由设备能力决定）
- 升级完成后设备可能自动重启，界面将提示重启并返回主界面

### 常见问题
- 低电量/文件错误/版本一致/校验失败会有对应状态提示，建议检查电量与文件来源
- 升级过程保持蓝牙连接稳定，避免切换后台或远离设备
- 如遇回连失败，返回主界面重新选择设备并确认服务 UUID 是否匹配
 - 若进度停滞，检查文件包是否完整、路径是否正确（建议使用 `_R.path.otas`）


## 1.5 4G OTA 升级

### 前置条件
- 设备端支持 4G 升级特性
- 已连接设备，进入 `4G OTA` 页面

### 操作步骤
- 打开：主界面 → `更新` → `4G OTA`
- 选择文件：点击 `选择 4G OTA 文件`，选择目标升级包
- 初始化：点击 `初始化` 完成准备
- 开始升级：点击 `开始`，观察 `传输中/设备处理` 状态及进度条
- 取消升级：点击 `停止` 中断流程

### 提示
- 完成后显示 `OTA 成功` 或失败原因；失败时检查错误码与文件有效性
- 4G 环境下可能存在网络波动，建议在良好信号条件下进行
 - 若云端返回错误码，请根据设备型号与固件要求核对升级包适配性

## 1.7 翻译模块（语音/字幕/通话翻译）

### 前置条件
- 设备已连接（若需设备侧参与录音/音频下发）
- 如使用云服务，需要在设置页填入 `AccessKey/SecretKey/AppID/Token` 等参数

### 操作步骤
- 打开设置页：进入 `翻译设置`，填入所需的云参数或开启本地模式
- 录音与翻译：进入 `翻译` 页面
  - 选择模式：面对面/仅录音 等
  - 选择录音策略、音频类型（`OPUS/JLA_V2` 等）、声道与采样率
  - 点击 `开始录音`，观察状态与字幕输出；点击 `停止` 结束
- 非交互下发：如需提升吞吐，开启“非交互式下发音频数据”（writeWithoutResponse）

### 提示
- 编解码工具：`OPUS/AV2`；字幕输出在界面字幕区域实时显示
- 可切换本地/云模式以适配不同测试场景
- 若云服务鉴权失败，请核对参数并确保网络连通
 - 使用外设麦克风时请确认音频路由正确（`AudioSession` 可辅助诊断）


## 1.8 TWS 健康数据

### 前置条件
- 设备支持 TWS 健康数据能力

### 操作步骤
- 打开：`默认设置` → `TWS 健康`
- 页面概览：顶部状态区显示设备健康能力、各传感器状态、实时步数、全天心率数据
- 操作菜单：下方为功能列表，包含以下操作项（点击后执行并在顶部显示结果/数据）：
  - 读取能力：读取设备健康能力（心率/血氧/步数/入耳传感器等），显示能力详情
  - 查询传感器状态：显示心率、血氧、步数与入耳传感器当前开关状态
  - 开启/取消心率监测：启动或停止心率采集；成功后会弹出提示
  - 开启/取消血氧监测：启动或停止血氧采集；成功后会弹出提示
  - 开启/取消步数监测：启动或停止步数采集；成功后会弹出提示
  - 开启/结束全天心率同步：开启后持续同步全天心率数据；结束则停止同步
  - 查询实时步数：立即拉取当前步数并在顶部显示
  - 设置步数轮询：弹窗输入轮询间隔秒数（建议≤300s），提交后按间隔自动刷新实时步数
  - 取消步数轮询：停止自动刷新

### 提示
- 不支持设备会显示空或提示；可返回主界面重新连接后再试
- 操作结果与错误信息会以轻提示方式显示（页面底部短暂弹出）
- 进入页面后可直接点击“读取能力/查询传感器状态”以确认设备支持范围

## 1.11 Auracast 广播

### 前置条件
- 设备支持 Auracast 功能（接收/发起角色）

### 操作步骤
- 打开：`默认设置` → `Auracast`
- 搜索：点击 `搜索` 扫描广播源，列表分页显示
- 登录：选择广播源后输入密码/密钥进行登录，观察登录状态
- 加入/退出：根据角色（接收端/发起端）加入或退出广播
- 修改密码：在页面中切换至修改密码区域并提交

### 提示
- 登录失败需检查密钥与设备角色权限；广播列表支持刷新与分页
- 安全建议：首次使用请修改默认密码，避免广播被未授权加入
 - 加入失败时检查广播源是否仍在播发、密码是否过期或更改


## 1.12 查找设备（手机找设备/设备找手机）

### 前置条件
- 设备支持查找功能

### 操作步骤
- 打开：`默认设置` → `查找设备`
- 设置参数：选择播放方式（全部/左/右/全部停止），开关是否发声，设置超时时间（秒）
- 执行动作：点击按钮发起“手机找设备”或“设备找手机”，观察设备端响铃或手机端铃声反馈
- 停止动作：在界面中选择停止或等待超时

### 可选参数说明
- `way`：播放方式（0 全部、1 左侧、2 右侧）
- `player`：播放源（0 APP、1 设备）
- `timeout`：超时时间（秒），到时自动结束播放
提示：
- 若长时间无响铃反馈，请检查设备音量与播放源选择是否正确

## 1.15 设置（Setting）

### 前置条件
- 进入主界面 → `设置`

### 可配置项
- 自定义蓝牙连接：开启后走自定义连接流程，更易覆盖不同广播类型设备
- 使用 ATT 通讯：启用 GATT over EDR；需输入服务 UUID（公版默认 `AE00`）
- 设备认证开关：关闭需设备端与其他端同时关闭；影响连接后的认证流程
- 日志开关与级别：便于调试（启用保存、时间戳、级别）

### 操作步骤
- 建议顺序：先确认蓝牙与权限 → 配置自定义连接/ATT → 开启日志（如需）
- 根据设备类型切换对应开关或输入参数 → 返回主界面执行扫描/连接 → 按功能测试
提示：
- 变更设置后，建议断开并重新连接设备，以确保新配置生效

## 1.32 ImitationNFR（通用 BLE 模拟）

### 前置条件
- 蓝牙已开启，系统授权正常（可能需要定位权限）

### 操作步骤
- 打开：切换至 `iNRf` Tab → 进入 `NFR 扫描`
- 扫描与刷新：下拉刷新触发 3 秒扫描，超时自动停止（界面顶端“Filter”可筛选/排序）
  - 名称筛选与排序：点击 `Filter` 弹窗，设置名称关键字与排序方式（`RSSI 降序` 或 `名称升序`），确认后重新扫描
- 连接/断开：在列表项点击 `连接`，连接成功后列表显示 `connected` 状态；再次点击切换为断开
- 进入详情：选择已连接设备进入 `外设详情页`，展示服务与特征分组

### 外设详情页（读/写/订阅）
- 读取特征：点击 `Read`，在该特征行显示最新值（十六进制 + ASCII）
- 写入特征：点击 `Write` 弹出输入框，选择数据类型与写入类型
  - 数据类型：`Hex Array`（示例：`01 02 FF`）、`UInt`（自动长度，小端）、`Bool`（`true/false/1/0`）、`UTF8`（文本）
  - 写入类型：`Request (Rsp)`（需要响应）或 `Command (NoRsp)`（不需响应）
  - 结果提示：页面弹出轻提示“写入成功/失败 + 错误信息”
- 订阅通知：点击 `Notify` 开关订阅/取消；最近一次推送显示在特征行红框文本处

### 额外说明
- 连接后每秒读取 `RSSI`；列表实时刷新信号强度
- 常见错误：蓝牙不可用、连接超时、服务/特征发现失败；均有轻提示反馈
- 扫描不到设备时，请降低筛选条件或确认设备处于广播状态

## 常见问题与故障排除（通用）
- 无法扫描到设备：确认蓝牙已开启、设备处于可发现状态、必要权限已授权；尝试靠近设备或重启蓝牙
- 连接后无服务/特征：检查是否启用 `ATT` 且服务 UUID 正确；断开后重连或在设置中调整连接方式
- 传输/升级失败：校验文件包与路径，保持前台与稳定连接；必要时更换资源或重启设备后重试
- 云服务鉴权失败：核对 `AccessKey/SecretKey/AppID/Token`，确保网络通畅与服务器可达
- 订阅无推送：确认特征支持 notify 并已订阅成功；检查设备端推送频率与条件

### 操作步骤补充（示例流程）
- 步骤1：进入 `NFR 扫描` 页面，点击 `Filter` 设置名称关键字与排序方式，点击 `确认`。
- 步骤2：在列表下拉刷新开始扫描（约 3 秒自动停止），等待出现目标设备。
- 步骤3：在目标设备行点击 `连接`，状态变为 connected 后继续操作。
- 步骤4：点击该设备进入 `外设详情页`，查看服务与特征分组。
- 步骤5：在某特征行执行操作：
  - 点击 `Read` 读取最新值（以“十六进制 + ASCII”显示）。
  - 点击 `Write` 打开输入弹窗，选择数据类型与写入类型，输入后点击 `Write` 确认。
  - 点击 `Notify` 开关订阅，观察特征行红框文本显示最近推送内容。
- 步骤6：需要断开时返回列表页点击 `断开`，或返回上一级退出详情页。
